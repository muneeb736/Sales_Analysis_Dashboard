# Sales Analysis Dashboard

An Excel-based sales analysis dashboard. Raw sales data was cleaned and then analyzed using Pivot Tables and charts.

## Workbook Sheets
- **Raw data**: original sales data
- **Cleaned data**: cleaned and prepared data
- **Pivot_Analysis**: Pivot Tables and PivotCharts
- **Dashboard**: final dashboard with key metrics, Sales by Category, Sales by Region, Total Profit and monthly Sales Trend

## Tools Used
Microsoft Excel: Pivot Tables, PivotCharts, Slicers, Power Query, Formulas
